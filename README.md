# KomikIndo Manga API

A standalone Express + TypeScript API that scrapes **KomikIndo** and
serves normalized manga data. Auto-generated by the MANGA Pembuat API Manga
module.

## Base URL

Setelah deploy, gunakan base URL berikut:

```
https://your-host/api
```

Contoh endpoint:
- `https://your-host/api/manga`
- `https://your-host/api/manga/1`
- `https://your-host/api/search?query=naruto`

> Set `BASE_URL` di file `.env` sesuai URL hasil deploy agar dapat
> di-detect otomatis oleh MANGA.

## Endpoints

| Method | Path | Description |
| ------ | ---- | ----------- |
| GET | `/api/health` | Health check |
| GET | `/api/sources` | Source metadata |
| GET | `/api/manga` | Manga list (`?page=&limit=`) |
| GET | `/api/manga/:id` | Manga detail |
| GET | `/api/manga/:id/chapters` | Chapter list for a manga |
| GET | `/api/chapter/:id` | Chapter detail |
| GET | `/api/chapter/:id/pages` | Chapter pages |
| GET | `/api/search?query=` | Search manga |
| GET | `/api/genres` | Genre list |
| GET | `/api/popular` | Popular manga |
| GET | `/api/latest` | Latest manga |

## Response format

```json
{ "success": true, "source": "KomikIndo", "data": [], "pagination": { "page": 1, "limit": 20, "total": 0 } }
```

Error:

```json
{ "success": false, "source": "KomikIndo", "error": "...", "code": "ERROR_CODE" }
```

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

## Build & start

```bash
npm run build
npm start
```

## Deployment

### Vercel
1. Push repository ke GitHub.
2. Connect repository ke Vercel.
3. Set environment variables (`SOURCE_URL`, `BASE_URL`, `CORS_ORIGIN`).
4. Deploy. Base URL: `https://<project>.vercel.app/api`.

### Railway
1. Push repository ke GitHub.
2. Connect repository ke Railway.
3. Set environment variables.
4. Deploy. Base URL: `https://<project>.up.railway.app/api`.

### Render
1. Push repository ke GitHub.
2. Buat Web Service baru dari repository ini.
3. Build command: `npm run build`. Start command: `npm start`.
4. Set environment variables.
5. Deploy. Base URL: `https://<service>.onrender.com/api`.

### Heroku
1. Push repository ke GitHub.
2. Connect repository ke Heroku.
3. Set environment variables.
4. Deploy. Base URL: `https://<app>.herokuapp.com/api`.

Setelah deploy, update `BASE_URL` di `.env` dengan URL hasil deploy,
lalu masukkan base URL tersebut di MANGA → Sumber Manga → Tambah API.
